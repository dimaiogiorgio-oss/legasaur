# Legasaur — Database Fantacalcio

Archivio storico completo della lega di fantacalcio **Legasaur**, dal 2016 ad oggi.

## Contenuti

- **Classifiche** — tutte le stagioni dalla 2016/2017 alla 2025/2026
- **Albo d'Oro** — vincitori di Legasaur, Coffa Italia/dei Capponi, +Europa League, Supercoffa
- **Storico Trofei** — classifica all-time per squadra
- **Rose** — formazioni complete con ruoli, squadre e costi

## Deploy

Sito statico single-page, nessuna dipendenza esterna. Basta caricare su GitHub Pages:

1. Crea un repository su GitHub
2. Carica tutti i file di questa cartella
3. Vai in **Settings > Pages** e seleziona il branch `main` come source
4. Il sito sara' disponibile su `https://<username>.github.io/<repo-name>/`
